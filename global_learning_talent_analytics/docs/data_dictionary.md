# Data dictionary
- employees.csv: employee_id, department, region, country_city, job_level, hire_date, employment_status.
- courses.csv: course_id, course_name, learning_category, duration_hours, mandatory_flag, course_owner, delivery_mode, active_flag.
- enrollments.csv: enrollment_id, employee_id, course_id, enrollment_date, due_date, completion_date, status, completed_hours, assessment_score, feedback_rating, source_system.
Synthetic data covers Jan 2025–Oct 2026. A small number of invalid values are intentionally injected to demonstrate data-quality detection and quarantine.
